Что нового в Transactioner

Версия 0.1.2

- Приложение умеет проверять ссылку или hash транзакции после вставки в поле TX.
- Для найденной транзакции подставляется ссылка на explorer.
- Для TRON и BSC депозитов подставляется сумма перевода.
- Для депозита Champion сумма в USDT/USD автоматически пересчитывается в EUR по дневному курсу.
- Для вывода Champion можно выбрать EUR или USD; если введена сумма в USD, приложение подставляет в шаблон сумму в EUR.
- Если кошелек/сеть содержит USDC, приложение выделяет тикер USDC в предпросмотре и при rich-copy.
- Для BTC-депозитов показывается предупреждение: в транзакции может быть несколько платежей, сумму нужно проверять внимательно.
- Улучшен поиск игроков: теперь можно искать не только по контактам, но и по никам/ID в румах.
- В шаблонах Nexa и Champion больше не появляются лишние слеши, если часть данных не заполнена.
- WhatsApp-номера очищаются от скрытых символов при сохранении и копировании шаблонов.
- Иконка приложения в левом меню ведет на главный экран поиска.

Файл с этим текстом находится в папке приложения: USER_RELEASE_NOTES.txt.
