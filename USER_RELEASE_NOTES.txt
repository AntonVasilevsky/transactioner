Что нового в Transactioner

Версия 0.1.19

- Поиск игроков теперь показывает результаты по мере ввода; если игрок не найден, его можно сразу создать с уже заполненным контактом. Email и телефон автоматически получают подходящий тип контакта.
- Шаблоны проверки привязки теперь можно редактировать и возвращать к встроенной версии в разделе «Привязки» настроек рума. Изменения сохраняются локально и сразу используются генератором.
- В Таблице 2 источник Site заполняет directusMessengers как `email: адрес`, а строки сохраняют введенные Nick, Room ID и Email.
- Список румов в проверке привязки учитывает румы, добавленные через справочник.
- Денежные суммы транзакций округляются до центов без лишних `.00`; для RedStar депозиты оформляются в USD, выводы поддерживают EUR/USD, а суммы в криптовалюте остаются без валютного префикса.

Версия 0.1.18

- Кошельки после обновления очищаются еще раз, чтобы убрать старые адреса, попавшие в локальные базы из предыдущих версий.
- Приложение больше не переносит кошелек между румами по совпадению монеты и сети: метод связывается с кошельком только внутри того же рума и типа сделки.
- Один и тот же физический адрес можно использовать в разных румах, но в программе это будут отдельные настройки каждого рума.
- Добавлены проверки, чтобы будущие агентские румы не получали чужой кошелек при одинаковых USDT TRC20/ERC20/BEP20 методах.

Версия 0.1.17

- Служебный апдейт для проверки сохранности локально внесенных кошельков после обновления.
- Кошельки не поставляются и не перезаписываются данными из релиза.

Версия 0.1.16

- Исправлена ошибка drag-and-drop в настройках методов, когда перестановка могла падать на UNIQUE constraint.
- При перетаскивании теперь обновляется только порядок метода и связанного кошелька, без изменения названия, валюты или сети.

Версия 0.1.15

- При обновлении кошельки в локальной базе очищаются один раз, чтобы убрать старые/дефолтные адреса и занести актуальные вручную.
- Сид-кошельки больше не создаются и не деактивируются автоматически: после сброса приложение не трогает вручную внесенные адреса.
- В настройках методов у кошелька появился отдельный переключатель "Кошелек активен".
- "Метод активен" и "Кошелек активен" теперь разделены: можно отключить кошелек без удаления метода.
- Красная кнопка "Удалить кошелек" удаляет адрес навсегда.

Версия 0.1.14

- Кошельки больше не поставляются как дефолтные данные приложения: новые пользователи заполняют адреса вручную.
- При обновлении версии уже сохраненные у пользователя кошельки не удаляются и не перезаписываются.
- Старые дефолтные кошельки, которые уже попали в локальную базу, становятся неактивными и пропадают с обычного экрана копирования, но остаются доступны в настройках.
- Методы депозитов и выводов отделены от адресов кошельков: приложение может проверять доступные сети и лимиты без передачи адресов между пользователями.
- Для RedStar и Nexa методы разнесены по отдельным сетям вместо объединенных строк.

Версия 0.1.13

- В "Инфо по румам" кошельки теперь отображаются из настроенных методов депозита, с лимитами и комиссиями.
- В настройках румов методы и кошельки связаны: редактирование депозитного метода обновляет соответствующий кошелек, а удаление метода убирает лишний кошелек.
- В списке методов добавлено drag-and-drop упорядочивание; этот порядок используется при показе кошельков.
- Список румов в "Инфо по румам" оставляет Nexa, Champion Poker и RedStar сверху, а остальные сортирует по частоте поиска.
- Исправлена обработка копирования кошельков: отказ Clipboard API больше не оставляет ошибку в консоли приложения.

Версия 0.1.12

- В заявках на депозит и вывод добавлены проверки методов, сетей и минимальных сумм по румам; для Champion Poker лимиты вывода проверяются отдельно по монете и сети.
- Проверка депозитных транзакций стала строже: сумма не подставляется, если найден кошелек другого рума или транзакция не относится к выбранному руму; старые транзакции показывают предупреждение.
- Улучшены шаблоны депозитов и выводов: добавлены английский и испанский форматы, корректная обработка BTC-сумм и короткое название Nexa.
- В "Инфо по румам" добавлены редактируемые методы и лимиты, удаление лишних методов, выбор языка для копирования кошельков и удобный переход к форме редактирования.
- В "Проверке привязки" улучшены шаблоны, поля рума/мессенджера и генерация строк для Google Sheets.

Версия 0.1.11

- Исправлена проверка TRON-депозитов: один и тот же перевод, который Tronscan возвращает в нескольких API-полях, больше не считается несколькими переводами.
- Защита для реальных batch-транзакций сохранена: если в одной TRON-транзакции есть несколько разных переводов на кошельки выбранного рума, приложение просит обработать сумму вручную.
- Подготовлены дистрибутивы для macOS и Windows x64, чтобы пользователи могли обновиться через GitHub Release.

Версия 0.1.10

- В депозитах приложение теперь ищет сумму в batch-транзакциях по сохраненным кошелькам всех румов.
- Если транзакция пришла на кошелек другого рума, сумма не заполняется автоматически и показывается предупреждение оператору.
- Для BTC batch-транзакций сумма подставляется только когда найден ровно один перевод на сохраненный кошелек выбранного рума.
- Если в одной batch-транзакции найдено несколько переводов на кошельки выбранного рума, приложение просит обработать сумму вручную.
- В шаблоне депозита RedStar ссылка на транзакцию теперь вставляется без префикса "tx id:".

Версия 0.1.9

- В "Инфо по румам" по умолчанию теперь открывается раздел "Сделка"; порядок переключателя изменен на "Сделка / Кошельки".
- Поиск румов в "Инфо по румам", настройках и "Проверке привязки" теперь понимает кириллицу: например, "некса", "редстар", "чемпион", "впт".
- При переходе из просмотра сделки в настройки открывается тот же рум/тип сделки/язык; при возврате просмотр сохраняет исходную сделку, даже если в настройках выбирали другой рум.
- В сделках добавлен язык ES; испанские версии можно создавать и редактировать в настройках.
- В "Проверке привязки" улучшены списки румов, мессенджеров и источников: при клике показывается полный список, а фильтр включается только при вводе.
- Для RedStar в строке Таблицы 2 поле "Сделки" автоматически заполняется как Standard.
- В "Проверке привязки" источник по умолчанию синхронизируется с выбранным мессенджером.
- Для ручного депозита Champion сумма по умолчанию считается EUR и подставляется со знаком €; при выборе USD сумма конвертируется в EUR для шаблона.

Версия 0.1.8

- Добавлен раздел "Проверка привязки" в левое меню.
- В проверке привязки появились шаблоны запросов по румам: Nexa, WPTG, RedStar, 888, TON Poker, PartyPoker, bwin, Guts Poker и default-шаблон для остальных.
- Для Таблицы 1 и Таблицы 2 генерируются готовые строки для вставки в Google Sheets.
- Игроки из проверки привязки не сохраняются в основную базу для нерабочих румов, чтобы не засорять список игроков.
- Для второй таблицы поле roomUsername теперь заполняется по правилу рума: для Nexa и других ID-based румов берется Room ID, для login/User ID румов берется username.
- Контакт мессенджера в шаблонах берется из поля "Контакт", а не из ника/username игрока.

Версия 0.1.7

- В "Инфо по румам" поле выбора рума стало поиском: можно сразу печатать название и выбирать из списка.
- Nexa, Champion Poker и RedStar закреплены наверху списка румов.
- В настройках румов по умолчанию открывается раздел "Сделки".
- В настройках румов добавлен такой же поиск по румам, включая неактивные румы.
- Улучшена форма добавления рума и редактирования сделок: после создания открывается прямая сделка, длинная вставка не прокручивает страницу вниз, галка активности перенесена выше.

Версия 0.1.6

- В разделе "Инфо по румам" появилась админка для редактирования справочника: сделки, кошельки и добавление новых румов.
- Перед сохранением правок справочника создается дополнительный backup базы данных.
- Черновики сделок не теряются при переключении RU/EN до нажатия "Сохранить".
- Неактивные румы скрываются из обычного списка "Инфо по румам", но остаются доступными в настройках.
- Видимость рума в справочнике переключается иконкой глаза.

Версия 0.1.5

- BTC hash теперь определяется через Blockstream: приложение подставляет ссылку на explorer, но не заполняет сумму автоматически.
- Для BTC-депозитов остается предупреждение, что транзакция может объединять несколько платежей и сумму нужно проверять вручную.
- В блоке "Файлы данных" больше нет отдельной строки "Папка бекапов"; показываются только БД и файл последнего бэкапа.

Версия 0.1.4

- На Windows и Mac версия приложения теперь заметно отображается в левом меню.
- В списке игроков блок "Файлы данных" показывает путь к базе данных, последнему бэкапу и папке бэкапов.
- В полях ввода работает правый клик: вставить, копировать, вырезать и выделить всё.
- Проверка транзакций в дистрибутиве использует локально упакованные API-ключи, не требуя файла в папке разработчика.

Версия 0.1.3

- Исправлено отображение иконки приложения в левом верхнем углу на Mac и Windows.

Версия 0.1.2

- Приложение умеет проверять ссылку или hash транзакции после вставки в поле TX.
- Для найденной транзакции подставляется ссылка на explorer.
- Для TRON и BSC депозитов подставляется сумма перевода.
- Для депозита Champion сумма в USDT/USD автоматически пересчитывается в EUR по дневному курсу.
- Для вывода Champion можно выбрать EUR или USD; если введена сумма в USD, приложение подставляет в шаблон сумму в EUR.
- Если кошелек/сеть содержит USDC, приложение выделяет тикер USDC в предпросмотре и при rich-copy.
- Для BTC-депозитов показывается предупреждение: в транзакции может быть несколько платежей, сумму нужно проверять внимательно.
- Улучшен поиск игроков: теперь можно искать не только по контактам, но и по никам/ID в румах.
- В шаблонах Nexa и Champion больше не появляются лишние слеши, если часть данных не заполнена.
- WhatsApp-номера очищаются от скрытых символов при сохранении и копировании шаблонов.
- Иконка приложения в левом меню ведет на главный экран поиска.
