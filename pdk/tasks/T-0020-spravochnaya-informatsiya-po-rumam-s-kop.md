## Goal

Запрос владельца (2026-10-05): в справочнике румов (экран информации о руме) должна быть справочная информация, которую можно скопировать игроку. Частый пример — лимиты на вывод. Сейчас лимиты хранятся в методах оплаты (`limits_text`; заполнены, например, у Champion на выводе), видны на экране рума только мелким текстом у кошелька депозита и используются для предупреждения о минимальной сумме в форме депозита/вывода; отдельного копирования нет.

## Acceptance

- Владелец уточнил, какая справочная информация нужна кроме лимитов на вывод (например, комиссии, способы вывода, сроки) и на каких языках её копировать.
- На экране рума есть блок с этой информацией и кнопкой копирования; текст на выбранном языке (RU/EN/ES), подписи — по общему правилу T-0019.
- Источник данных — тот же справочник (без второй копии лимитов); предупреждение о минимальной сумме в форме депозита/вывода работает как раньше.
- Тесты на формирование текста; `npm run lint`, `npm test`, `npm run build` — ok; `pdk check` — 0 errors; ручная проверка владельца.
