## Goal

Владелец (2026-10-15): некоторые игроки не знают, где взять хеш, и присылают скриншот перевода из биржи (сумма, адрес нашего кошелька, сеть, время в своём часовом поясе). Нужно в депозите найти этот перевод в блокчейне и подставить ссылку в «TX ID / ссылка».

### Разбор примера (2026-10-15)

Скриншот Binance: «-25 USDT», Network BSC, Address `0x7fa4e95b52813d5eefd860d22bf8f19467bc9adc` (наш кошелёк Кукоин, USDT BEP20), Amount 25.01, Network fee 0.01, Date 2026-10-15 21:12:39 (время игрока), статус Processing. Сообщение пришло в 13:12 по времени оператора (UTC−3) = 16:12 UTC.
Найдено (Binplorer `getAddressHistory`, только чтение): `0x8e4018d7c519d88c88152c2716d302e75103ea84cc7666ad774fda534b22cbb6`, 2026-10-15 14:12:56 UTC, 25.0000 USDT, от `0xa180fe01…` (адрес биржи). Значит, у игрока UTC+7, скриншот прислан через ~2 часа после перевода. В тот же день — перевод 0 USDT от похожего адреса (`0xef3a4b47…` рядом с настоящим `0xef3aeff9…`) — «отравление адреса», такие переводы отбрасывать.

### Решения владельца (2026-10-15)

- Кошелёк оператор выбирает руками из выпадающего списка; по всем кошелькам не ищем (поменяем, если понадобится).
- Сумма — сумма перевода (в примере 25); комиссию не вводим; ищем эту сумму.
- Период по умолчанию — последние 2 часа от текущего момента. Раскрывающаяся опция «Время сообщения» (из мессенджера): тогда окно — 2 часа до времени сообщения.
- Сети — те, что есть в кошельках для депозитов выбранного рума (сейчас: USDT TRC20, USDT ERC20, USDC ERC20, USDT BEP20, BTC, ETH); не-блокчейн (Skrill, Luxon Pay) в списке поиска нет.
- Время со скриншота и часовой пояс игрока пока не вводим.

## Acceptance

- В депозите рядом с «TX ID / ссылка» — кнопка «Нет хеша — найти перевод», раскрывает блок: кошелёк (активные кошельки для депозита выбранного рума в поддерживаемых сетях; если рум не выбран — подсказка), сумма, свёрнутая опция «Время сообщения» (ЧЧ:ММ; дата — сегодня, а если время ещё не наступило — вчера; дату можно поправить), кнопка «Найти».
- Окно поиска: без времени сообщения — [сейчас − 2 ч, сейчас]; со временем сообщения — [сообщение − 2 ч, сообщение + 15 мин] (биржа может провести перевод через несколько минут после скриншота «Processing»). Окно вынесено в одно правило с тестами; пример выше находится (14:12:56 при окне с 14:12:00).
- Только входящие на выбранный кошелёк, в монете кошелька (USDT/USDC — контракт сети; BTC/ETH — нативные), сумма совпадает с введённой (с точностью до копейки для стейблкоинов, до введённых знаков для BTC/ETH); нулевые и пылевые переводы отбрасываются.
- Результат: список кандидатов — время по часам оператора и UTC, минуты:секунды, сумма, отправитель (коротко), ссылка на обозреватель; выбор подставляет ссылку в «TX ID / ссылка», дальше работает обычная проверка транзакции. Ни одного — «Не найдено за … попробуйте указать время сообщения»; больше одного — показать все с предупреждением «несколько переводов на эту сумму — уточните у игрока».
- Обозреватели и ключи — как в существующих проверке транзакций и поиске рейкбека (Tronscan, Etherscan v2, Binplorer, BTC-источник резолвера); ошибки сети и лимиты API показываются понятно, ключи не логируются.
- Тесты: окно времени, совпадение суммы, отбрасывание нулевых/пылевых, разбор ответов каждого обозревателя на сохранённых примерах (без сети). lint, тесты, build — ok; ручная проверка владельца на реальном случае.
- Позже (не в этой задаче): поиск по всем кошелькам рума, минуты со скриншота и часовой пояс игрока, распознавание вставленного скриншота.
